# 3D House Renderer

Plan furniture in a 3D model of a real house, at true scale. Open `app.html` in a browser (needs internet for Three.js from jsDelivr).

Houses (toolbar switch, or link hash `#heddon-greta`):
- **21 Conquest Close, Rutherford** – traced from the Ray White listing plan (53.6 px = 1 m).
- **76 Main Road, Heddon Greta** – traced from the listing plan (29 px = 1 m), with the owners' planned kitchen.

Features:
- Views: 3D orbit, Plan (top-down), Walk (first person). W A S D moves in every view; Q E turn the 3D view; Shift is faster.
- Furniture catalogue with typical Australian sizes, the Nick Scali San Remo range (all layouts and 20 leather colours), and editable W/D/H, colour, price (AUD), notes.
- Red = clashes with a wall/window/joinery. Amber = blocks a doorway.
- Floor switch: current floors, Tilemall Avoca 600x300 Matt Bianco tile, Preference Floors Oakleaf HD PLUS Blackbutt.
- Measure tool, Cutaway walls, shopping list with total.
- Each house's layout autosaves in the browser. Use Save / Load to copy a layout to another device.

Verify real room sizes on site before buying large items.
