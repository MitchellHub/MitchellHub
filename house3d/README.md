# 21 Conquest Close – 3D furniture planner

Open `app.html` in a browser (needs internet for Three.js from jsDelivr).

- Walls, windows, doors, joinery traced from the Ray White listing floor plan at its printed scale (53.6 px = 1 m, approx. ±5 cm).
- Views: 3D orbit, Plan (top-down), Walk (first person).
- Catalogue of typical Australian furniture sizes. Drag to move, R to rotate, edit W/D/H, colour, price (AUD), notes.
- Red = clashes with a wall/window/joinery. Amber = blocks a doorway.
- Measure tool, Cutaway walls, shopping list with total.
- Layout autosaves in the browser. Use Save / Load to copy the layout text to another device.

Verify real room sizes on site before buying large items.
